# Good First Issues

New to yaagents and looking for a way to contribute? Pick one of these:

- **Add a Postman collection** for the `examples/store/` API
- **Translate a skill file** to a new AI tool (e.g. add `examples/store/skills/aider.md` for Aider)
- **Add an MDX recipe** to the docs site showing how to add a custom plugin
- **Add a Mermaid diagram** for the plugin lifecycle to `/reference/plugin-interface/`
- **Expand the conformance-test CLI** to cover the v0.3 `failed_dependency` response shape
- **Add an OpenAPI example** to `openapi/components/` for the `clarification_required` body shape
- **Add a `LICENSE` snippet** to the cli + sdk-fastapi READMEs (consistency with other components)
- **Improve a stub plugin** — write a regex-only `prompt-sanitize` implementation as a community PR

Comment on (or open) an issue referencing the item before starting work so we can avoid duplication.
