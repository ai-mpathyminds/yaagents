## NFR Addendum — A-4 platform-engineer pass (2026-05-17)

### OQ-5 resolution: SBOM format pick

**Format: SPDX 2.3 (JSON), generated by `syft`.**
Rationale: SPDX 2.3 is the default output of GitHub's dependency graph,
integrates natively with `gh release upload`, and is the format expected by
GitHub's automated Dependabot alerts. `syft` (Anchore) is the reference
implementation; its `spdx-json` output validates against the SPDX 2.3 JSON
schema. CycloneDX was considered — better SBOM-tooling ecosystem for
vulnerability correlation — deferred to PI2-yaa when Cosign signing ships
(ADR PI1-yaa-0005). OQ-5 is resolved; REL-5 updated to specify `syft spdx-json`.
