# ADR PI1-yaa-0003 — Python packaging + build tooling + TS build shape

Status: [Accepted]
Date: 2026-05-17
PI: PI1-yaa
Deciders: yaagents-architect (input: python-developer OQ-4, frontend-developer OQ-6)

## Context

Three PyPI packages (`yaagents-fastapi`, `yaagents-client`, `yaagents-cli`) and
one npm package (`@aimpathyminds/yaagents-client`). OQ-4: Hatch vs Poetry. OQ-6: pure ESM vs
dual ESM+CJS for the TS client.

## Decision

1. **Hatch (resolves OQ-4)** for all three Python packages. `pyproject.toml`
   with `[build-system] requires=["hatchling"]`, PEP 621 metadata, dynamic
   version from a single `__about__.py` per package. Rationale: PyPI Trusted
   Publisher docs are Hatch-first; no lockfile-in-CI ceremony; lighter than
   Poetry for library (not app) distribution.
2. **Each package is independently versioned at `0.1.0`** with its own
   `pyproject.toml` (no monorepo workspace tool — three flat packages under
   their component dirs). Shared profile-version constant is duplicated as a
   literal `"v0.1"` (not a shared dep) to keep packages dependency-free.
3. **Dual ESM + CJS for `@aimpathyminds/yaagents-client` (resolves OQ-6).** `tsup` (or
   equivalent) emits `dist/index.mjs` + `dist/index.cjs` + bundled
   `dist/index.d.ts`; `package.json` `exports` map carries `import`/`require`
   conditions. **Zero runtime dependencies** (uses `fetch`; Node ≥18 / modern
   browser). Rationale: CJS compat is required for Jest-based consumers; the
   10–15% bundle overhead is acceptable for a client library and the PRD lists
   dual-format as the target.
4. **`Supports-YAAgents-Profile: v0.1`** declared in package metadata: Python
   via `[project] classifiers`/`urls` + a `__profile__` attribute; npm via a
   `yaagents.profile` field in `package.json` + exported `PROFILE_VERSION`.

## Consequences

- REL publishing WIs use Hatch build commands + PyPI Trusted Publisher; npm WI
  uses provenance + dual-bundle (ADR PI1-yaa-0005 covers OIDC mechanics).
- Three independent `pyproject.toml`s means three Trusted-Publisher
  registrations (one per PyPI project) — enumerated in REL WIs.
- Zero-dep TS client constrains the client to `fetch`; no axios.

## Alternatives considered

- *Poetry* — rejected: heavier, lockfile/CI friction, Trusted-Publisher path
  less first-class than Hatch.
- *Monorepo (uv workspace / pnpm workspace)* — rejected: four packages across
  two language ecosystems in one repo; per-package flat config is simpler for
  v0.1 and matches the component-dir layout.
- *Pure ESM npm* — rejected: breaks Jest-CJS consumers (PRD OQ-6 trade-off).
