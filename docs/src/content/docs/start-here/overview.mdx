# Overview <Badge text="Stable" variant="success" />

yaagents is an **Agentic REST Profile** — a specification, a gateway, and a set of SDKs that
expose AI agents as typed, governed REST APIs.

The core idea in one sentence: instead of `POST /agents/invoke`, ship
`POST /campaigns/{id}/optimizations` — with typed outcomes, RBAC, tenant context,
and audit handled once at the gateway, not in every service.

## What yaagents is NOT

- Not an agent framework — bring LangGraph, CrewAI, Semantic Kernel, or plain Anthropic SDK
- Not a chatbot infrastructure — yaagents governs REST API boundaries, not chat UIs
- Not an A2A replacement — A2A / AGNTCY govern agent-to-agent calls; yaagents governs application-to-agent calls
- Not an MCP replacement — MCP connects agents to tools and context; yaagents connects apps to agent capabilities
- Not a model provider abstraction — use the Anthropic SDK / OpenAI SDK for that
