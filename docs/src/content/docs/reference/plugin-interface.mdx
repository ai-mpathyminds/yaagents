## What this page will cover

- The `Plugin` interface (`Init(cfg map[string]any) error`, `Handler(next http.Handler) http.Handler`, `Shutdown(ctx context.Context) error`)
- Plugin registration via Go `init()` import side-effect
- Configuration schema (YAML key mapping, type coercion)
- Context key conventions for passing data between plugins
- Error handling and short-circuit semantics
