## What this page will cover

- `createYaAgentsClient(config)` — base URL, auth token factory, tenant ID, fetch override
- Result-style API: `result.type === 'clarification_required'` TypeScript discriminated union
- Exception-style helpers: `throwOnClarification`, `throwOnValidationFailed`, `throwOnError`
- Browser + Node.js compatibility — ESM and CJS builds, no Node-specific globals
- Declared YAAgents Profile version (`YAAGENTS_PROFILE_VERSION` export)
