This walkthrough takes you from zero to a running agentic endpoint in ≤10 minutes.
You will start the ecommerce `store` reference example, make your first agentic call,
then use an AI-tool skill to extend the mock recommender into a real LLM-driven agent.

---

## 1. Prerequisites

Before you begin, confirm you have:

- **Docker** (Desktop or Engine) — `docker --version`
- **git** — `git --version`

No cloud account or API key is required for the mock demo. You will need one when you
extend the recommender in Step 4.

---

## 2. Clone and run the store example

<Steps>

1. **Clone the repo and start the compose stack:**

   ```bash
   git clone https://github.com/ai-mpathyminds/yaagents.git
   cd yaagents/examples/store
   docker compose up --build
   ```

2. **Wait ~15 seconds for both services to become healthy, then verify:**

   ```bash
   docker compose ps
   ```

   You should see `yaagents-gateway` and `store` both healthy.

</Steps>

<Aside>
  The gateway listens on `localhost:8120`. The store service listens on `localhost:8121`
  (also directly accessible for testing). All agentic traffic routes through the gateway.
</Aside>

---

## 3. First agentic call — product recommendations

POST to `POST /products/p-1/recommendations`. Product `p-1` is wireless headphones.
The service returns same-category recommendations as an `AgenticResult`.

```bash
curl -s -X POST http://localhost:8120/products/p-1/recommendations \
  -H "Content-Type: application/json" \
  -d '{"limit": 3}' \
  | python3 -m json.tool
```

**Expected response — 200 `application/json`:**

```json
{
  "seed_product_id": "p-1",
  "recommendations": [
    {"id": "p-2", "name": "Bluetooth speaker", "category": "electronics", "price": 49.99, "brand": "AudioCore"},
    {"id": "p-3", "name": "Smart watch", "category": "electronics", "price": 199.99, "brand": "TickTock"},
    {"id": "p-5", "name": "Mechanical keyboard", "category": "electronics", "price": 129.99, "brand": "KeyMaster"}
  ],
  "reasoning": "Same category as 'Wireless headphones' (electronics)"
}
```

### Personalise with a customer ID

Pass `X-Customer-Id: c-1` to filter out products already purchased by that customer:

```bash
curl -s -X POST http://localhost:8120/products/p-1/recommendations \
  -H "Content-Type: application/json" \
  -H "X-Customer-Id: c-1" \
  -d '{"limit": 3}' \
  | python3 -m json.tool
```

Customer `c-1` (Alice) has purchased `p-1` and `p-4`. The response excludes `p-4`
from the electronics recommendations.

<Aside type="tip">
  The `reasoning` field is where LLM-powered personalisation shines. With the mock
  it is a simple category string; with a real LLM it becomes a personalised explanation
  driven by the customer's purchase history.
</Aside>

## 4. Make it real — extend with an AI-tool skill

The mock recommender in `src/store/recommender.py` returns same-category products
with no LLM. The `skills/` directory contains starter prompts for five AI coding tools
that walk you through replacing the mock with a real LLM call in **10–20 minutes**.

<Steps>

1. **Pick your AI tool and open its skill file:**

   | Tool | Skill file |
   |------|-----------|
   | Claude Code | `examples/store/skills/claude-code-agent.md` |
   | Claude.ai (web/desktop) | `examples/store/skills/claude-web.md` |
   | GitHub Copilot | `examples/store/skills/github-copilot.md` |
   | OpenAI / ChatGPT | `examples/store/skills/openai-codex.md` |
   | Cursor | `examples/store/skills/cursor.md` |
   | Other | `examples/store/skills/generic-prompt.md` |

2. **Copy the Starter Prompt 1** from the skill file and paste it into your AI tool.
   Share the `recommender.py` source (or point your tool at it) and your `products.json` file.

3. **Apply the AI-generated changes** to `src/store/recommender.py`. Add your LLM API key
   as an environment variable (e.g. `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`).

4. **Rebuild and test:**

   ```bash
   docker compose up --build

   curl -s -X POST http://localhost:8120/products/p-1/recommendations \
     -H "Content-Type: application/json" \
     -H "X-Customer-Id: c-1" \
     -d '{"limit": 3}' | python3 -m json.tool
   ```

   The `reasoning` field should now contain personalised LLM output instead of
   `"Same category as 'Wireless headphones' (electronics)"`.

</Steps>

---

## 5. Tear down

```bash
docker compose down
```
