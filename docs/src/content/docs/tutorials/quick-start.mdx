# Quick Start <Badge text="Stable" variant="success" />

In 10 minutes you'll:

1. Start the yaagents gateway
2. Run the `store` reference example (a product-recommendations agent)
3. Call the agentic endpoint and see a real `AgenticResponse.success` body
4. (Optional) Open a skill prompt for your AI coding tool and extend the
   mock into a real LLM-driven agent

## Prerequisites

- Docker
- 10 minutes

## Step 1 — Pull the gateway image

```bash
docker pull ghcr.io/ai-mpathyminds/yaagents-gateway:0.3.0
```

## Step 2 — Clone and run the store example

```bash
git clone --depth 1 https://github.com/ai-mpathyminds/yaagents.git
cd yaagents/examples/store
docker compose up -d
docker compose ps   # both gateway + store should be "healthy"
```

The store service exposes one agentic endpoint:
`POST /products/{id}/recommendations`. It's a Python service built
with [yaagents-fastapi](/reference/sdk-fastapi/) using the
`@agentic_operation` decorator — the same SDK contract any real agent
service uses.

## Step 3 — Make your first agentic call

```bash
curl -sX POST http://localhost:8120/products/p-1/recommendations \
  -H 'Content-Type: application/json' \
  -H 'X-Actor-Subject: c-1' \
  -d '{"limit": 3, "exclude_purchased": true}' | jq
```

**Response** (HTTP 200 — vendor type `application/vnd.yaagents.agentic+json`,
headers include `X-YAAgents-Profile: v0.3`):

```json
{
    "seed_product_id": "p-1",
    "recommendations": [
        {
            "id": "p-2",
            "name": "Bluetooth speaker",
            "category": "electronics",
            "price": 49.99,
            "brand": "AudioCore"
        },
        {
            "id": "p-3",
            "name": "Smart watch",
            "category": "electronics",
            "price": 199.99,
            "brand": "TickTock"
        },
        {
            "id": "p-4",
            "name": "USB-C charger 65W",
            "category": "electronics",
            "price": 24.99,
            "brand": "PowerUp"
        }
    ],
    "reasoning": "Same category as 'Wireless headphones' (electronics)"
}
```

## What just happened

- The gateway received your request at `/products/p-1/recommendations`
- The plugin chain ran (token-validator, tenant-injector — both default-on)
- The request was proxied to the `store` service
- The store handler — decorated with `@agentic_operation` — produced an
  `AgenticResponse.success(...)` body
- The SDK set the `X-YAAgents-Profile: v0.3` response header
  automatically; you didn't write any of that wiring

The whole point of yaagents: **the contract is the URL + the response
shape**. Your agent code stays domain-focused.

## Step 4 (optional) — Extend the mock with a real LLM

The mock recommender returns same-category products. To replace it with
a real LLM-driven recommender, open a skill prompt for your AI coding
tool:

- [`skills/claude-code-agent.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/claude-code-agent.md) — Claude Code CLI
- [`skills/claude-web.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/claude-web.md) — Claude.ai web
- [`skills/github-copilot.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/github-copilot.md) — GitHub Copilot Chat
- [`skills/openai-codex.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/openai-codex.md) — OpenAI Codex
- [`skills/cursor.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/cursor.md) — Cursor IDE
- [`skills/generic-prompt.md`](https://github.com/ai-mpathyminds/yaagents/blob/main/examples/store/skills/generic-prompt.md) — any AI coding tool

Copy the starter prompt into your tool. In ~10-20 minutes the AI extends
the mock recommender into a real LLM-driven one while preserving the
Profile shape. Same `curl` command; now powered by real LLM.
