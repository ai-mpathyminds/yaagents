# Planned How-to Guides

The how-to guides below are on the v0.4 roadmap. Each covers a concrete task with
a worked example. Individual stub pages are available via the links below — subscribe
to [GitHub Discussions](https://github.com/ai-mpathyminds/yaagents/discussions) to
get notified when they ship.
