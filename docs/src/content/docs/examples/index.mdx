Explore end-to-end examples. New to yaagents? Start with the **store** example — it is the
example used in the [Quick Start](/tutorials/quick-start/).

## Recommended starting point

- [store (Python)](/examples/store/) — POST /products/{id}/recommendations; mock recommender
  + 6 AI-tool skills to extend it into a real LLM agent in 10–20 min
- [store-go (Go)](/examples/store-go/) — Go mirror of the store example using sdk-go

## Alternative examples

- [campaign-api (Python)](/examples/campaign-api/) — five agentic flows with RBAC, tenant
  context, and audit logging; good for martech / enterprise patterns
- [campaign-api-go (Go)](/examples/campaign-api-go/) — same flows via sdk-go
- [llm-gateway](/examples/llm-gateway/) — SSE streaming + per-tenant concurrency
