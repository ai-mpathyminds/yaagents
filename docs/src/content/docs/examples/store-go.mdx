**Stack:** YAAgents gateway + Go net/http service (sdk-go)

Go mirror of [store (Python)](/examples/store/) using the Go server SDK (`sdk-go`).
Demonstrates `sdkgo.AgenticResponse`, `sdkgo.FromRequest()`, and `sdkgo.Write()` on
the `POST /products/{id}/recommendations` endpoint.

---

## Start the stack

```bash
git clone https://github.com/ai-mpathyminds/yaagents.git
cd yaagents/examples/store-go
docker compose up --build
```

The gateway listens on `http://localhost:8120`.

---

## Sample call

```bash
curl -s -X POST http://localhost:8120/products/p-1/recommendations \
  -H "Content-Type: application/json" \
  -H "X-Customer-Id: c-1" \
  -d '{"limit": 3}' | python3 -m json.tool
```
