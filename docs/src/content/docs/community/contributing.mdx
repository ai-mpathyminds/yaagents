## Contributing to yaagents

We welcome contributions! Please read this guide before opening a pull request.

### DCO sign-off

All commits must be signed off with `git commit -s` (Developer Certificate of Origin). This certifies that you have the right to submit the contribution.

### PR checklist

Before opening a pull request, verify:

- [ ] Tests pass: `pnpm test` (TypeScript client) / `go test ./...` (gateway/SDK) / `pytest` (Python SDK/client)
- [ ] Linter clean: `pnpm lint` / `golangci-lint run` / `ruff check`
- [ ] DCO sign-off present on all commits
- [ ] `CHANGELOG.md` updated for user-visible changes
- [ ] Documentation updated if adding or changing public API

### Contributing a plugin

If you're contributing a new first-party plugin or proposing an existing plugin be bundled with the gateway, please open a discussion on [GitHub Discussions](https://github.com/ai-mpathyminds/yaagents/discussions) first. We evaluate plugins against the default-plugin design principle before bundling.

Community plugins (not bundled but linked from the registry) are welcome without prior discussion — publish to GitHub with the topic `yaagents-plugin`.
