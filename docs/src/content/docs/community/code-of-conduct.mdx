The yaagents project is committed to providing a welcoming and inclusive environment for all contributors and users.

## Our standards

We expect all community members to:

- **Be respectful** — treat others with kindness and assume good intent
- **Be constructive** — focus feedback on ideas and code, not people
- **Be inclusive** — welcome contributors of all backgrounds and experience levels
- **Be honest** — be transparent about limitations, errors, and concerns

## Scope

This Code of Conduct applies to all project spaces — GitHub Issues, Pull Requests, Discussions, and any other official project channels.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers via [GitHub Discussions](https://github.com/ai-mpathyminds/yaagents/discussions).

All reports will be handled with discretion.
