## What this page will cover

- LangChain — excellent for chaining LLM calls; not a REST API governance layer
- Anthropic SDK / Claude API — powerful model access; not a deployment infrastructure
- OpenAI Assistants API — opinionated managed service; not open-source or self-hostable
- yaagents — the REST profile + gateway layer that governs how agents are _exposed_ regardless of underlying framework
- When to use each (and when to combine them — yaagents + LangChain is a common pattern)
