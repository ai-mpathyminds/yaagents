## What this page will cover

- Why the five first-party plugins are on by default (not opt-in)
- The security argument: opt-out is safer than opt-in for auth + audit
- Cost argument: shared middleware is cheaper than per-service implementations
- Override philosophy: any plugin can be replaced without touching agent service code
- "Paved road" principle — sane defaults, escapable via configuration
