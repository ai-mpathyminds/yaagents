## Finding releases

All yaagents releases are published on GitHub:

- **GitHub Releases** — [github.com/ai-mpathyminds/yaagents/releases](https://github.com/ai-mpathyminds/yaagents/releases)
- **Gateway Docker images** — `ghcr.io/ai-mpathyminds/yaagents-gateway:<version>`
- **Python packages** — `yaagents-fastapi`, `yaagents-client`, `yaagents-cli` on PyPI
- **TypeScript package** — `@aimpathyminds/yaagents-client` on npm
- **Go modules** — `github.com/ai-mpathyminds/yaagents-sdk-go`, `github.com/ai-mpathyminds/yaagents-client-go`
