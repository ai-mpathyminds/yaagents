## v0.3.0

*First public release.*

### Added

- **Profile v0.3** — 10 normative agentic response types
- **Gateway** — pluggable middleware (5 first-party plugins)
- **sdk-fastapi** — Python server SDK
- **sdk-go** — Go server SDK
- **client-python** — Python client SDK
- **@aimpathyminds/yaagents-client** — TypeScript/JavaScript client SDK
- **client-go** — Go client SDK
- **CLI** — `validate-openapi`, `conformance-test`, `init fastapi`, `init go`
- **campaign-api examples** — Python + Go reference implementations
- **GitHub Pages docs site** — this documentation

### Notes

- `prompt-sanitize` and `otel-audit` plugins ship as functional stubs in v0.3; production hardening planned for v0.4
- Helm chart and Kubernetes deployment guide planned for v0.4
