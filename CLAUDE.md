# yaagents — Claude Code Instructions

## Product Overview

**yaagents** is a source-available **Agentic REST Profile**: it lets teams expose agentic capabilities as ordinary domain resource operations (`POST /campaigns/{id}/optimizations`, not `/agents/invoke`) with typed HTTP responses, gateway-controlled access, OpenAPI contracts, and native clients. Framework-neutral — bring any agent runtime; yaagents standardizes the *interface*. Public OSS, dual-licensed (Community + Commercial; source-available, **not** OSI). Runs on the portfolio's third parallel lane `yaa`.

## Conventions

- API shape is resource-oriented; the Response Profile status×media-type table in `system-refs/YAAgents_PRD_README.md` is **normative** — copy verbatim, never paraphrase.
- JSON logging with `request_id`/correlation-id propagation; `/healthz` `/readyz` on the gateway.
- Every published package declares the YAAgents Profile version it supports.
- Publishing uses **OIDC trusted publishing** (PyPI/npm/GHCR) — no long-lived tokens in CI.
- License wording follows GTM README §12 (source-available / fair-code), with the "not legal advice / legal review pending" disclaimer carried verbatim.
- Commit trailers on every agent commit: `Agent: <name>`, `WI: <id>`, `Co-Authored-By:`.
